日子 · 技术支持

Days · Support

使用或购买遇到问题，先看下面常见问答；仍未解决可发邮件。

If something goes wrong, try the FAQ below. Still stuck? Email us.

怎么添加日子？How do I add a day?

打开 App → 点「添加日子」→ 填写名称并选择日期 → 保存。只需这两步。

Open the app → tap Add a day → enter a name and pick a date → Save. That’s it.

「就是今天 / 还剩 N 天 / 已过 N 天」怎么算？How are Today / N days left / N days ago counted?

按自然日计算，列表、详情和桌面小组件用同一套口径，保持一致。

By calendar day. The list, detail screen, and Home Screen widgets use the same count.

小组件天数怎么和 App 里对不上？Why doesn’t the widget match the app?

在系统桌面长按 → 编辑小组件 / 添加小组件 → 选择「日子」或 Days。添加后应与详情一致；若刚改过日期，稍等小组件刷新或重进桌面再看。

On the Home Screen, touch and hold → Edit / Add Widget → choose Days. It should match the detail count. After changing a date, wait for a refresh or leave and return to the Home Screen.

主题只能预览不能用？I can preview a theme but not use it?

免费主题点「使用」即可。带锁的主题需解锁 Pro；可先预览，点「使用」会进入购买。

Free themes can be used immediately. Locked themes need Pro. Preview first; Use opens purchase.

购买没成功 / 提示失败？Purchase failed or was cancelled?

确认网络正常，用你的 Apple ID 完成系统购买框。若点了取消，会提示「已取消」；真正失败可再试一次。仍不行：App Store 退出后重登，或稍后重试。

Check the network and finish the Apple ID sheet. Cancel shows Cancelled; a real failure can be retried. If it still fails, sign out and back into the App Store, or try later.

换机 / 重装后主题没了？Themes disappeared after a new phone or reinstall?

打开日子 → 设置或 Pro 入口 → 点「恢复购买」。需用购买时的同一个 Apple ID。

Open Days → Settings or the Pro sheet → Restore Purchases. Use the same Apple ID you bought with.

会不会要订阅？Is this a subscription?

不会。Pro 为一次买断（非消耗型），不是订阅。

No. Pro is a one-time unlock (non-consumable), not a subscription.

收不收集我的数据？要日历权限吗？Do you collect my data? Do I need calendar access?

不收集个人数据。日子与主题保存在本机；不需要相机或相册权限。详见隐私政策。

We don’t collect personal data. Days and themes stay on device. Camera and photo library access are not required. See the privacy policy.
