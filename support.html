日子 · 技术支持

使用或购买遇到问题，先看下面常见问答；仍未解决可发邮件。

怎么添加日子？

打开 App → 点「添加日子」→ 填写名称并选择日期 → 保存。只需这两步。

「就是今天 / 还剩 N 天 / 已过 N 天」怎么算？

按自然日计算，列表、详情和桌面小组件用同一套口径，保持一致。

小组件天数怎么和 App 里对不上？

在系统桌面长按 → 编辑小组件 / 添加小组件 → 选择「日子」。添加后应与详情一致；若刚改过日期，稍等小组件刷新或重进桌面再看。

主题只能预览不能用？

免费主题点「使用」即可。带锁的主题需解锁 Pro；可先预览，点「使用」会进入购买。

购买没成功 / 提示失败？

确认网络正常，用你的 Apple ID 完成系统购买框。若点了取消，会提示「已取消」；真正失败可再试一次。仍不行：App Store 退出后重登，或稍后重试。

换机 / 重装后主题没了？

打开日子 → 主题 / Pro 入口 → 点「恢复购买」。需用购买时的同一个 Apple ID。

会不会要订阅？

不会。Pro 为 ¥6 买断（非消耗型），不是订阅。

收不收集我的数据？要日历权限吗？

不收集个人数据。日子与主题保存在本机；不需要相机或相册权限。详见隐私政策。
